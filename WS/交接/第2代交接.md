## 一、一句话结构

```
主图（Black room / prison，2D 横向）
   └─ 走到 BOSS 附近（距离 ≤120）→ 存档 → 跳 BOSS 战
BOSS 战（boss-battle，2.5D 等距 64×64 / 48×48 实时战斗）
   └─ 胜利 → 写入 bd=true → 进入下一场景 / 失败 → 重载重来
```

两套主图**各有一份独立的 js 副本**（历史分叉），BOSS 战则是**一份公用引擎 + 两个场景目录**。这个不对称是踩坑的主要来源，后文会反复强调。

## 四、核心机制详解

### 4.1 存档

| 项 | 内容 |
| --- | --- |
| 键名 | `localStorage['black_room_prison_save']` |
| 写入口 | `Black room\js\game-state.js` 的 `exportSaveToLocalStorage()`；首行 `if (isGuestMode()) return;` |
| 兼容读 | 短键/长键双向兼容（如 `lv`/`level`、`cw`/`currentWeapon`、`hc`/`hasCross`、`hcm`/`hasClownMask`、`is`/`inventorySlots`） |
| BOSS 击败标记 | `bd`（= bossDefeated）；另有按场景记录的 `ws_boss_cleared` 由 `config.js` 维护，**已不再用于跳转拦截** |
| 游客模式 | URL 带 `?guest=1` 时所有落盘失效，用于试玩与自动化测试 |

### 4.2 场景流转

```
主图（任意）  玩家与 BOSS 距离 ≤120 且 !__bossJumping
        ├─ 置 __bossJumping = true
        ├─ try { exportSaveToLocalStorage() } catch → console.warn 后继续
        ├─ hasManualSave = true（避免 beforeunload 弹「是否离开」）
        └─ 跳转 boss-battle/<场景>/index.html?scene=xxx&lv=等级[&guest=1]
                          ↓
                intro 3.2s → fight（dist<26 唤醒 BOSS）
                          ↓
        胜利：markBossDefeated() → bd=true
              黑屋 → ../../../prison/prison.html?load=black
              监狱 → ../../../prison/prison.html
        失败：原地重载
```

`pageshow` 事件里会把 `__bossJumping` 复位为 false —— 这是"从 BOSS 战返回主图后 BOSS 不会再触发"的修复点，别删。

### 4.3 BOSS 战引擎

| 项 | 说明 |
| --- | --- |
| 场景注入 | 场景页在 `<head>` 里 `window.__SCENE__ = 'blackroom' | 'prison'`；`config.js` 读它（也兼容 `?scene=`） |

已做的优化（改渲染时别推翻）：
- 地台菱形整图离屏烘焙，按缩放级别复用，不逐帧重建；

### 8.2 三个必知的"假故障"

1. **BOSS 不动不一定是卡死**：玩家距离 ≥26 格时 `bossAwake` 为 false，BOSS 完全静止。先把玩家挪到 12 格内再判断。
2. **`MAP.isSolid` 的单位是格**：`isSolid(boss.x+40, boss.z)` 是"40 格外"，早已越界返回 true，会误判成"四周全是墙"。正确探针是 ±1 / ±2 / ±3 格。
3. **headless 页面加载慢**：直接 `drain(5)` 后取 `MAP` 会报 `MAP is not defined`，应轮询 `typeof MAP !== 'undefined'` 再执行。

## 九、雷区清单（按踩坑代价排序）

1. **双场景副本不同步**：`Black room\js\` 与 `prison\js\` 是两份独立文件，改一边必须手动同步另一边。行数不同属历史分叉，**禁止整文件覆盖**。
2. **顶层 `const/let` 重复声明**：多个 `<script>` 共享同一词法作用域，同名会直接 `SyntaxError` 导致整个模块不运行。公共状态只在 `config.js` 声明一次。
3. **BOSS 出生点压在实心格**：`bossHome` 必须落在空地，且四周留出 ≥ `r*0.75`（1.275 格）余量。2026-11-14 黑屋祭坛台座 `fill(30,6,4,3,3)` 正压住 `(32,8.2)`，导致 BOSS 全程站桩。
4. **资源路径随页面层级变化**：`boss-battle/js/` 里引用场景素材是 `assets/`，共用素材是 `../assets/`，音乐是 `../../音乐/`，返回链接是 `../../../`。层级算错就是一片 `ERR_FILE_NOT_FOUND`。
5. **`terrain_new.js` / `terrain_20261101_212126_904.js` 是死文件**：改了不生效，先确认改的是 `terrain.js`。
